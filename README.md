# 🧠 MemoTag Website- Functional One-Pager

A fully responsive, animated, and high-conversion one-page website built for **MemoTag** — an AI-powered dementia care platform.

🌐 [Live Site](https://memotag-onepager.vercel.app)

---

## 📌 Project Overview

This is a public-facing explainer site for MemoTag, built with **Next.js**, **Tailwind CSS**, and **Framer Motion**, following a clean, modern, and animated one-page format. It highlights:

- The problem MemoTag is solving  
- The solution and product details  
- MemoTag’s unique value proposition  
- Traction and stats  
- A compelling call-to-action for stakeholders  

---

## 🚀 Tech Stack

- **Framework**: Next.js (App Router)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Backend**: Supabase (waitlist form)
- **Hosting**: Vercel
